# g-cou

Guilherme Couto's personal blog, live at [g-cou.online](https://g-cou.online). Built with Next.js App Router, React 19, Tailwind CSS v4, and TypeScript. Articles are written in Markdown with YAML frontmatter and statically generated at build time. Content is bilingual (Portuguese and English).

## Stack

- **Next.js 16** (App Router) — routing and static generation
- **React 19** — UI
- **Tailwind CSS v4** — styling, with custom design tokens in `app/globals.css`
- **TypeScript** — type safety
- **gray-matter** — Markdown frontmatter parsing
- **remark / rehype** — Markdown-to-HTML pipeline
- **rehype-prism-plus** — syntax highlighting
- **rehype-slug** — heading ids for the table of contents

## Project Structure

```
/articles/<locale>/   # Markdown article files, one folder per locale (pt, en)
/app/[locale]/         # Locale-scoped App Router pages
/components/           # Layout primitives (Main, Footer, TableOfContents, etc.)
/lib/                  # Core utilities (articles.ts, markdown-to-html.ts, utils.ts)
/lib/i18n/             # Locale config and dictionaries (config.ts, en.ts, pt.ts)
/middleware.ts         # Redirects locale-less paths to the preferred locale
```

## Internationalization

`lib/i18n/config.ts` defines the supported locales (`pt`, `en`) and the default (`pt`). `middleware.ts` inspects the `Accept-Language` header and redirects any path without a locale prefix to `/<locale>/...`. UI strings live in `lib/i18n/en.ts` and `lib/i18n/pt.ts`, loaded per request via `getDictionary(locale)`.

## Content

Articles live in `/articles/<locale>/` as `.md` files with the following frontmatter:

```markdown
---
title: "Article Title"
description: "Short description"
date: "2026-01-27"
tags: ["tag1", "tag2"]
published: true
---
```

Only articles with `published: true` are displayed. They are sorted by date, newest first. A matching filename in another locale folder is the same article translated.

## Routes

- `/<locale>` — Home page with profile and the list of published articles
- `/<locale>/<slug>` — Individual article page (statically generated), with a table of contents on wide viewports
- `/<locale>/rss.xml` — RSS feed for that locale
- `/robots.txt`, `/sitemap.xml` — generated by `app/robots.ts` and `app/sitemap.ts`

## Environment

URLs are read from environment variables at build/render time:

```
RSS_URL           # canonical site URL used in the feed
GITHUB_REPO_URL   # footer "Code" link
X_URL             # footer X link
LINKEDIN_URL      # footer LinkedIn link
TRADEX_URL        # bio link
EC_URL            # bio link
ALURA_URL         # bio link
```
